# Business Model

## Target users

- University students completing lab courses
- Graduate students and research assistants doing repeated analysis/plotting
- Small labs that need consistent analysis records and figures

## Value proposition

Reduce repetitive work between raw measurements and report-ready figures, while keeping the
calculation transparent, reproducible, and scientifically defensible.

## Pricing hypotheses (not yet validated)

### Free

Basic import, summary statistics, linear fit, basic charts, limited projects and exports.

### Pro — 29 CNY/month (hypothesis)

Advanced fits and uncertainty, more chart types, vector export, more projects, report export,
saved chart styles.

### Team — from 99 CNY/month (hypothesis)

Shared projects/templates, batch analysis, team data management.

These are hypotheses for Phase 5 validation. No real billing is enabled.

## Validation plan

1. Interview 10–20 target users about current workflow and pain.
2. Observe a complete analysis with 5–10 users.
3. Measure repeat usage and export success.
4. Test willingness to pay with a controlled trial and clear entitlement boundaries.
5. Compare variable cost per active user with realistic revenue scenarios.

No fabricated orders, users, conversion rates, or revenue.

## Cost posture

Local computation, deterministic algorithms, and low infrastructure cost. Avoid paid AI calls
for core results. Track model/API cost per iteration when relevant.

## Key metrics

- New real users
- First successful analysis rate
- 7/30-day repeat usage
- Export success rate
- Defect rate
- Trial-to-paid conversion
- Revenue per user and variable cost per user
- Monthly net revenue
